FAQ

Straight questions, straight answers.

Is it safe to run a curl | bash?

Yes. The scripts are short, open for anyone to read and live in the public repository. They only write to your home folder, never ask for an admin password, and you can inspect the code in your browser first. Uninstalling cleans everything up with the uninstall.sh (see "How do I uninstall?" below).

Why the name Mopivo?

Mopivo is the name of both the project and the app — short, catchy and easy to remember. All internal identifiers use the same name. Since the app was never released before, there's no legacy baggage or migration: just install and use it.

Does it work on Wayland?

Yes. Images work in your session as usual. Video wallpapers use a desktop layer when available and, if needed, fall back to fullscreen per monitor. Auto-pause has a small limitation on Wayland — flagged on the Video page.

Do I have to pay for an API?

No. Wallhaven (SFW), Safebooru, Waifu.im, your folders and Wallrus work with no sign-up. Pexels, Unsplash and Pixabay ask for a free key — the app tells you which one is missing and the Help Center shows you how to create it in 2 minutes.

How do I uninstall?

However you prefer — they all do the same cleanup (stops the video, removes the app, shortcut, icon, settings and translations; your current wallpaper stays untouched):

Direct command (recommended): curl -fsSL https://raw.githubusercontent.com/zonaro/mopivo/master/uninstall.sh | bash
In the downloaded code: ./uninstall.sh (or ./scripts/uninstall.sh / make uninstall)
Via the installer: ./install.sh --uninstall or curl …/install.sh | bash -s -- --uninstall

Where are the install and uninstall scripts?

In the repository root: install.sh installs (fetches the remote code if run via curl) and uninstall.sh removes. Both accept --help, --ref <branch|tag> and --yes. The real logic lives in scripts/install.sh and scripts/uninstall.sh — the root ones just call or download when needed. Direct links: install.sh · uninstall.sh.
